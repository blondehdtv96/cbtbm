================================================================================
CARA MEMPERBAIKI ERROR 404 KARENA CACHE
================================================================================

MASALAH:
Browser masih request ke URL lama:
http://127.0.0.1:8000/cbtbm/public/exam/13/save-jawaban

Padahal kode sudah diperbaiki ke URL relatif:
/exam/13/save-jawaban

PENYEBAB:
=========
1. Browser cache JavaScript lama
2. Laravel view cache belum di-clear
3. Service worker (jika ada)

SOLUSI LENGKAP:
===============

STEP 1: CLEAR LARAVEL CACHE
----------------------------
Buka terminal/command prompt di folder project:

php artisan view:clear
php artisan cache:clear
php artisan config:clear
php artisan route:clear

STEP 2: HAPUS COMPILED VIEW MANUAL
-----------------------------------
Hapus semua file di folder:
storage/framework/views/

Windows:
del /Q storage\framework\views\*

Linux/Mac:
rm -rf storage/framework/views/*

STEP 3: CLEAR BROWSER CACHE
----------------------------
Di browser (Chrome/Edge/Firefox):

Cara 1: Hard Refresh
- Windows: Ctrl + Shift + R
- Mac: Cmd + Shift + R

Cara 2: Clear Cache Manual
1. Tekan F12 (Developer Tools)
2. Klik kanan tombol Refresh
3. Pilih "Empty Cache and Hard Reload"

Cara 3: Clear All Cache
1. Tekan Ctrl + Shift + Delete
2. Pilih "Cached images and files"
3. Time range: "All time"
4. Klik "Clear data"

STEP 4: RESTART SERVER (JIKA PERLU)
------------------------------------
Jika pakai php artisan serve:
1. Stop server (Ctrl + C)
2. Start lagi: php artisan serve

Jika pakai XAMPP:
1. Stop Apache
2. Start Apache

STEP 5: TEST ULANG
-------------------
1. Buka browser BARU (Incognito/Private)
   - Chrome: Ctrl + Shift + N
   - Firefox: Ctrl + Shift + P
   - Edge: Ctrl + Shift + N

2. Login ke sistem

3. Buka ujian

4. Tekan F12 → Tab "Console"

5. Jawab 1 soal

6. Perhatikan log:
   [SAVE] URL: /exam/13/save-jawaban  ← HARUS RELATIF
   [SAVE] Response status: 200 OK  ← HARUS BERHASIL

JIKA MASIH 404:
===============

Cek 1: Apakah file sudah benar?
-------------------------------
Buka: resources/views/exam/mengerjakan.blade.php
Cari: const url = 
Harus ada: const url = `/exam/${ujianId}/save-jawaban`;

BUKAN: const url = `{{ route('exam.save-jawaban', $ujian->id) }}`;

Cek 2: Apakah route terdaftar?
-------------------------------
php artisan route:list | findstr save-jawaban

Harus ada:
POST | exam/{ujian}/save-jawaban

Cek 3: Apakah middleware benar?
--------------------------------
Buka: routes/web.php
Cari: save-jawaban
Pastikan ada middleware: ['auth', 'role:siswa']

Cek 4: Cek compiled view
-------------------------
Buka: storage/framework/views/
Cari file yang namanya mirip: ...mengerjakan.blade.php...
Buka file tersebut
Cari: save-jawaban
Pastikan URL-nya relatif: /exam/

JIKA MASIH TIDAK BISA:
======================

-----------------------------------

Solusi Ekstrim 2: Gunakan Browser Lain

-------------------------------------------------
