================================================================================
PERBAIKAN ERROR 419 PAGE EXPIRED
================================================================================

MASALAH:
Saat anti-cheat terdeteksi, muncul halaman putih:
"419 | PAGE EXPIRED"
Tanpa tombol atau informasi apapun.

SOLUSI:
========

1. HALAMAN CUSTOM ANTI-CHEAT VIOLATION
   File: resources/views/exam/anti-cheat-violation.blade.php
   
   Fitur:
   ✓ Icon warning dengan animasi
   ✓ Penjelasan pelanggaran yang terdeteksi
   ✓ Info: jawaban tersimpan, akun logout, dll
   ✓ Tombol besar "Kembali ke Halaman Login"
   ✓ Auto-redirect dalam 10 detik
   ✓ Design responsive untuk mobile

2. UPDATE CONTROLLER
   File: app/Http/Controllers/ExamController.php
   
   Perubahan:
   ✓ Tampilkan view custom (bukan redirect)
   ✓ Error handling dengan try-catch
   ✓ Handle jika user sudah logout
   ✓ Fallback ke login jika error

3. GLOBAL EXCEPTION HANDLER
   File: app/Exceptions/Handler.php
   
   Perubahan:
   ✓ Catch semua error 419 di route exam
   ✓ Tampilkan halaman violation otomatis
   ✓ Logging untuk debugging
   ✓ Redirect ke login untuk route non-exam

CARA KERJA:
===========

SKENARIO 1: Pindah Tab (Normal)
1. Siswa pindah tab 3x
2. Sistem deteksi pelanggaran
3. Saat kembali: submit exam & logout
4. Tampilkan halaman violation
5. Auto-redirect ke login (10 detik)

SKENARIO 2: Session Expired (Error 419)
1. Siswa idle lama, session habis
2. CSRF token invalid
3. Sistem coba submit → Error 419
4. Exception Handler catch error
5. Tampilkan halaman violation
6. Auto-redirect ke login (10 detik)

KONFIGURASI:
============

Agar session tidak expired terlalu cepat, edit .env:

SESSION_LIFETIME=180  # 3 jam (default 120)

Atau edit config/session.php:
'lifetime' => env('SESSION_LIFETIME', 180),

TROUBLESHOOTING:
================

Jika masih muncul 419 putih:
php artisan view:clear
php artisan cache:clear
php artisan config:clear

Restart server:
# Windows XAMPP
Restart Apache dari XAMPP Control Panel

# Linux
sudo service apache2 restart

MONITORING:
===========

Cek log CSRF error:
tail -f storage/logs/laravel.log | grep "CSRF token mismatch"

Cek log anti-cheat:
tail -f storage/logs/laravel.log | grep "anti_cheat_violation"
