CARA DEBUG: JAWABAN TERSIMPAN NULL DI DATABASE
================================================================================

MASALAH:
Di database tabel jawaban_siswas, kolom jawaban_dipilih = NULL
Padahal siswa sudah menjawab soal.

================================

1. FRONTEND (mengerjakan.blade.php)
   ✓ Logging detail di setiap step
   ✓ Alert jika save gagal
   ✓ Verify response dari server
   ✓ Retry otomatis jika error

2. BACKEND (ExamController.php)
   ✓ Logging request & response
   ✓ Validasi input lebih ketat
   ✓ Verify data setelah save
   ✓ Error handling lengkap

===============

KEMUNGKINAN PENYEBAB:
=====================

1. JAVASCRIPT TIDAK JALAN
   Gejala: Tidak ada log di console
   Solusi: Cek console untuk error JavaScript

2. REQUEST TIDAK SAMPAI BACKEND
   Gejala: Ada log console, tidak ada log Laravel
   Solusi: Cek URL, CSRF token, network

3. BACKEND MENERIMA NULL
   Gejala: Log Laravel: "jawaban": null
   Solusi: Cek payload di network tab

4. DATABASE CONSTRAINT
   Gejala: Log OK, database masih NULL
   Solusi: Test insert manual di database

5. CACHE ISSUE
   Gejala: Semua OK, halaman guru masih NULL
   Solusi: Clear cache

QUICK FIX:
==========

1. Clear cache:
   php artisan cache:clear
   php artisan view:clear
   php artisan config:clear

2. Restart server:
   # Windows XAMPP
   Restart Apache dari XAMPP Control Panel
   
   # Linux
   sudo service apache2 restart

3. Test ulang dengan ujian baru
