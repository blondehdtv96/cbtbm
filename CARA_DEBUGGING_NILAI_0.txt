LANGKAH 2: CEK NETWORK TAB
---------------------------
1. F12 → Tab "Network"
2. Jawab 1 soal
3. Cari request "save-jawaban"
4. Klik request tersebut
5. Cek:
   - Status: Harus 200 OK (bukan 404, 500, 419)
   - Response Tab: {"success": true, "message": "Jawaban berhasil disimpan"}
   - Payload Tab: {bank_soal_id: 123, jawaban: "A"}

LANGKAH 3: CEK DATABASE
------------------------
Jalankan:
php check_jawaban.php

Atau query manual:
mysql -u root -p
use cbtbm;

SELECT * FROM peserta_ujians ORDER BY id DESC LIMIT 1;
-- Catat peserta_ujian_id, misal: 45

SELECT 
    js.id,
    js.bank_soal_id,
    js.jawaban_dipilih,
    js.is_correct,
    js.nilai
FROM jawaban_siswas js
WHERE js.peserta_ujian_id = 45;

YANG HARUS DICEK:
- Apakah ada record? (Jika tidak, jawaban tidak tersimpan)
- Apakah jawaban_dipilih terisi? (Jika NULL, ada masalah di frontend)
- Apakah is_correct dan nilai sudah diupdate? (Jika NULL, ada masalah di grading)

KEMUNGKINAN MASALAH:
--------------------

1. JAWABAN TIDAK TERSIMPAN
   Gejala: Database kosong
   Penyebab: Request gagal, CSRF invalid, session expired
   Solusi: Cek network tab, cek CSRF token

2. JAWABAN TERSIMPAN TAPI TIDAK DINILAI
   Gejala: jawaban_dipilih terisi, is_correct NULL
   Penyebab: Tidak ada opsi jawaban benar di database
   Solusi: Cek tabel opsi_jawabans, pastikan ada is_correct = 1

3. JAWABAN DINILAI TAPI NILAI AKHIR 0
   Gejala: is_correct = 1, nilai terisi, peserta.nilai = 0
   Penyebab: bobot_nilai = 0 atau perhitungan salah
   Solusi: Cek bobot_nilai di bank_soals

4. PATH URL SALAH
   Gejala: 404 Not Found
   Penyebab: Path tidak sesuai instalasi
   Solusi: Sudah diperbaiki dengan route() helper

QUICK FIX:

php artisan cache:clear

php artisan view:clear

Restart Apache/Nginx
